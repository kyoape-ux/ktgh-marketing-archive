⚙️ 系統初始設定

連線 Google Sheets 後端

資產資料統一存於 Google Sheets，方便備份、多人共用。首次設定約 5 分鐘，之後不用再動。

部署步驟（首次 5 分鐘）
1
開新 Google Sheet（標題例：「光田設計資產庫_2026」）
2
點頂部選單 Extensions → Apps Script
3
把 scripts/AssetVault.gs 整份內容複製貼上 Apps Script 編輯器，按 儲存
4
點右上 Deploy → New deployment，類型選 Web app，
Execute as: Me，Who has access: Anyone，按 Deploy
5
首次會跳警告 → 點 Advanced → Go to ...(unsafe) → Allow 完成授權
6
複製 Web app URL（網址含 /exec），貼到下方欄位 → 測試連線
URL 僅儲存於本機瀏覽器 localStorage。
為什麼可以「Anyone access」但仍安全？
因為 URL 本身就是密碼。未公開的隨機 URL 無法被搜尋到。Apps Script 以你的身份執行，所有資料寫入只有你的 Sheet。建議：不要把 URL 貼到公開頁面或 GitHub commit 訊息中。

啟用 AI 自動建檔功能

輸入免費的 Google Gemini API Key，啟用「一鍵 AI 建檔」。AI 會看圖辨識內容，自動填入類別、節慶、日期、標籤等欄位。沒有也能手動建檔。

Google Gemini API Key
僅儲存於本機 localStorage。免費額度每分鐘 15 次、每天 1,500 次。
如何取得免費 API Key？
1. 前往 aistudio.google.com/apikey（Google 帳號登入）
2. 點 Create API key，選任一個專案
3. 複製 AIza… 開頭的 Key 貼上

✓ 完全免費。不啟用 AI 也能手動建檔，只是要自己填欄位。
