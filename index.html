⚙️ 系統初始設定

連線 Google Sheets 後端

資產資料統一存於 Google Sheets，方便備份、多人共用。首次設定約 5 分鐘，之後不用再動。

公用後端 — 所有裝置自動連線
尚未設定

一次性設定後，任何瀏覽器、任何電腦打開網站就自動連線，不再需要逐台設定。 設定方式：把你的 GAS Web App URL 貼到 GitHub repo 的 config.js 裡。

直接開啟 config.js
⚠️ 安全提醒　GitHub Pages 是公開網頁，URL 會被任何訪客看到。內部使用通常 OK，但若日後資料被異常寫入：到 Apps Script → Manage deployments → 建立新版本（URL 會更新）→ 把新 URL 貼回 config.js 覆蓋即可。
首次部署 GAS 步驟（如果還沒做過）
1
開新 Google Sheet（標題例：「光田行銷數位歸檔中心_2026」）
2
點頂部選單 Extensions → Apps Script
3
把 scripts/KTGHArchive.gs 整份內容複製貼上 Apps Script 編輯器，按 儲存
4
點右上 Deploy → New deployment，類型選 Web app，
Execute as: Me，Who has access: Anyone，按 Deploy
5
首次會跳警告 → 點 Advanced → Go to ...(unsafe) → Allow 完成授權
6
複製 Web app URL（網址含 /exec），貼到下方欄位 → 測試連線
URL 僅儲存於本機瀏覽器 localStorage。
為什麼可以「Anyone access」但仍安全？
因為 URL 本身就是密碼。未公開的隨機 URL 無法被搜尋到。Apps Script 以你的身份執行，所有資料寫入只有你的 Sheet。建議：不要把 URL 貼到公開頁面或 GitHub commit 訊息中。
多裝置設定 — 匯出 / 匯入

切換到 B 電腦 / 平板？把這台電腦設定好的 GAS URL、Gemini API Key、標籤庫匯出成 JSON，到另一台電腦匯入即可，不需要重新部署 GAS。

⚠️ 匯出的 JSON 包含 GAS URL 與 API Key，請妥善保管，勿傳到公開頻道（如 LINE 群組、Email 附件）。建議用 Google Drive「僅自己」或私訊傳遞。
