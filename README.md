# 光田設計資產庫 · AssetVault

光田綜合醫院行銷部數位歸檔系統｜純前端 + Google Sheets + Gemini AI 自動建檔

## 主要功能

### 📚 數位資產庫
- **資產總覽**：縮圖卡片網格、即時搜尋、類別/年份多重篩選、統計儀表板
- **新增資產**：拖曳上傳自動產生 webp 壓縮縮圖、完整 metadata 表單
- **年度回顧**：依年份 → 節慶/活動分組呈現產出時間軸（適合報 KPI）
- **快速索引**：醫師形象照、空間照、門診表封面、海報、活動視覺、社群圖卡 6 大專屬面板
- **網路硬碟路徑**：一鍵複製到剪貼簿，貼到檔案總管網址列即可開啟

### ✨ AI 自動建檔（核心亮點）
拖檔進去 → 點「一鍵 AI 建檔」→ Gemini 看圖一秒填入：
- 推薦標題（從圖中文字推測）
- 類別判斷（從 11 種預設選擇）
- 節慶辨識（從你的標籤庫匹配）
- 日期提取（如圖中有可見日期）
- 標籤建議（從標籤庫挑 2–5 個）
- 全文 OCR（自動寫入備註）
- 信心度標記（高/中/低 + 判斷依據）

讓 5 年舊檔回溯從每筆 2 分鐘 → 20 秒。

### 🎯 行銷專案管理（Project Management）
完整記錄每一個行銷專案的設計、印製、佈置、費用、地點。

**核心特色**：
- 📷 **縮圖式相簿總覽**：每個專案有封面照片，跟資產庫同樣視覺語言
- 📦 **細項清單**：紅包/春聯/海報/燈籠⋯⋯各算一項，含數量、單位、費用、分發地點
- 🏥 **6 院區複選**：向上、沙鹿、大甲、長青、通霄光田、仁馨樂活園區
- 🖼️ **多張現場照片**：最多 4 張，可指定封面
- 🔁 **「往年比照辦理」**：點開專案會自動列出歷年同類型專案，含費用對比
- 💰 **預算自動加總**：細項費用合計
- 🏷️ **七大類型**：節慶/活動/環境美化/單次美化/招募/形象/其他

### 📊 數位化儀表板（Dashboard）
給主管看的成果展示頁，集中呈現系統的數位化改革成效。

**展示內容**：
- 累計歸檔總數（資產 + 專案 + 範本）
- 數位化前後對照表（散落個人電腦 vs 雲端可查）
- 年度建檔趨勢圖（資產 vs 專案）
- 各院區涵蓋現況
- KPI 達成現況（建檔率、欄位完整率、院區涵蓋率、估算節省工時）

### 📋 範本中心（Template Center）
集中管理行銷部會用到、需要傳閱單位確認的空白表單。檔案放在 Google Drive，本系統只索引連結。

**七大分類**：
- 📨 邀約類（媒體邀約、講者邀請、嘉賓邀約）
- ✅ 審核類（文稿審核、設計審核、影片審核）
- 🎨 設計類（設計需求單、改稿單、印刷規格）
- 🤝 合作類（外包合約、跨單位合作備忘錄）
- 📝 同意書（受訪同意、肖像授權、場勘確認）
- 📐 規範類（CI 手冊、Logo 規範、品牌色票）
- 📦 其他

**功能**：搜尋、分類篩選、一鍵下載/複製連結、隨時新增/編輯/刪除、自動辨識檔案類型 icon（PDF/DOC/XLS/PPT/ZIP/IMG）。

### 📚 標籤庫
四大分類維護一致的標籤詞典，避免「節慶/節日/特殊節日」這類同義不同寫：
- 🎉 節慶類：母親節、父親節、春節⋯
- 🏷️ 主題類：衛教、招募、活動、形象、品牌⋯
- 👥 客群類：女性、長者、兒童、職員⋯
- 📍 用途類：FB 社群、IG 貼文、印刷大圖⋯

新增資產時可從標籤庫一鍵點選；AI 建檔也會優先從庫中選用。

## 技術架構

| 元件 | 用途 |
|------|------|
| 純前端（HTML/CSS/Vanilla JS）| 介面、互動、縮圖壓縮 |
| Google Sheets + Apps Script | 資產資料儲存、永久備份 |
| Google Gemini 2.5 Flash | AI 自動建檔（免費額度每天 1500 次）|
| localStorage | 標籤庫、API Key、後端 URL 設定 |

## 快速開始

### 1. 部署 Google Sheets 後端（5 分鐘，一次性）
1. 開新 Google Sheet（標題例：「光田設計資產庫_2026」）
2. Extensions → Apps Script
3. 複製 [`scripts/AssetVault.gs`](scripts/AssetVault.gs) 內容貼上，儲存
4. Deploy → New deployment → Web app
   - Execute as: **Me**
   - Who has access: **Anyone**
5. 授權，複製 Web app URL

### 2. 設定前端
1. 開啟 `index.html`（或 GitHub Pages 版）
2. 進入「後端連線」，貼上 Web app URL，測試連線
3. （建議）「AI 引擎」貼上免費 Gemini API Key 啟用自動建檔

### 3. 開始建檔
- 新增資產 → 拖曳圖片 → 點「一鍵 AI 建檔」→ 確認後儲存

## 資料表結構（自動建立於 Google Sheets）

`id, title, category, year, date, festival, event, client, tags, drivePath, extLinks, designer, usage, notes, thumb, createdAt, updatedAt`

縮圖以 base64 webp 內嵌儲存（單筆約 30–50 KB）。

## 安全性

- Sheets URL 與 API Key 僅儲存於本機 localStorage
- 所有資料停留在你自己的 Google 帳號
- 縮圖經瀏覽器壓縮後才送出，原檔不離開電腦
